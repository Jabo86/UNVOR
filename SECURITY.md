# UNVOR vulnerability reporting

Please do not disclose security vulnerabilities, private messages, credentials, personal identifiers or exploit details in public issues.

Use GitHub's private vulnerability reporting feature in the affected software repository if enabled. If it is unavailable, ask a maintainer for an approved private reporting channel without including sensitive details in the public request. A dedicated UNVOR security address has not yet been confirmed.

Include the affected component, version, environment, expected behavior, impact and sanitized reproduction evidence through the private channel. Test only accounts, devices and infrastructure you own or have explicit permission to test. Coordinate disclosure with the maintainers. No bounty or response-time guarantee is established by this page.
