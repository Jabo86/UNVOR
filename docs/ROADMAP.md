# UNVOR roadmap

[Home](../README.md)

Roadmap items describe priorities, not promised dates. A check is complete only when supporting evidence is recorded.

| Milestone | Acceptance criteria | Status |
| --- | --- | --- |
| Unified identity | Approved logo, consistent project-facing naming | In progress |
| Documentation hub | Product guides, download catalog, security and contribution policies | Prepared |
| Chat pilot validation | Two-device messaging, attachments, calls, background delivery and error handling | Pending release-specific evidence |
| Launcher validation | Device installation, upgrade, UI and local tools | Pending release-specific evidence |
| Relay federation | Peer authentication, failover, retention and metadata tests | In development |
| Stable distribution | Signed releases, source references, hashes and trusted fingerprints | Pending |
| Open-source transition | Confirm rights and compatible licenses for each component | Pending |
| Website integration | Public URL, verified download links and privacy controls | Pending |

The development repositories retain their existing history and legal attribution. Changes to application identity and release signing require a separate migration and device testing plan.
