# ADR-002 — Distribution and documentation hub

Status: adopted for the current documentation repository.

Context: UNVOR needs a coherent public identity while preserving existing software history, release signing and obligations.

Decision: use the UNVOR repository as the documentation and release discovery hub. Keep existing source and artifacts in their verified locations until reviewed migration and redistribution are authorized.

Consequences: the catalog can refer to upstream resources. No duplicate binaries or claims of new stable releases until rights, provenance and signatures are established.
