# Licensing and attribution

[Home](../README.md)

The goal is an open-source UNVOR ecosystem. That goal is not yet a statement that all current components are open source.

The existing [application license](https://github.com/Jabo86/ultron-android/blob/main/LICENSE) is Business Source License 1.1, with restrictions on redistribution and a stated change date of 6 September 2030 to GPL-3.0-or-later. Review the license itself and all component notices before redistributing software. This documentation hub does not change those terms or remove attribution.

A new license for this documentation and its visual assets has not yet been approved by the maintainer. Publication of this hub does not grant additional software or trademark rights. Before adopting an open license, confirm ownership, contributor rights, third-party obligations and asset terms. Proposed options for review: CC BY 4.0 for original documentation, and a suitable OSI-approved software license for each code repository.
