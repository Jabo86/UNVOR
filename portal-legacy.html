06 // Knowledge base

Domande frequenti.

UNVOR è un sistema operativo?

No. Il progetto comprende un launcher Android, una chat e una rete di relay. GrapheneOS è il sistema di riferimento sul Pixel 8.

Serve un account Google?

L'obiettivo è offrire componenti utilizzabili senza account Google o dipendenze obbligatorie dai suoi servizi.

Serve un server personale?

La Chat pilota usa un gateway di prova; il laboratorio relay non è integrato.

Posso scaricare le applicazioni?

La Chat 366 è disponibile nel repository originale; il nuovo hub contiene una release in bozza.
