# Contributing to UNVOR

Use this hub for documentation corrections and product suggestions. Implementation changes belong in the affected development repository. Start with the [architecture](docs/ARCHITECTURE.md) and [roadmap](docs/ROADMAP.md).

Keep proposed changes focused, explain the problem and expected outcome, include evidence where relevant, and disclose limitations. Do not include personal information or secrets. Preserve attribution and respect applicable licenses. Security issues follow the private [reporting policy](SECURITY.md).

English, Italian and Spanish contributions are welcome.
